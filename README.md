# Iris Species Predictor (Streamlit App)

This is a simple web application built using [Streamlit](https://streamlit.io/) that predicts the species of an iris flower based on four input features: sepal length, sepal width, petal length, and petal width. The prediction is powered by a `RandomForestClassifier` from scikit-learn, trained on the classic Iris dataset.

---

## 🔍 Features

- Interactive sliders for inputting flower measurements.
- Instant prediction of Iris species (Setosa, Versicolor, or Virginica).
- Built-in machine learning model using scikit-learn.
- Fully responsive web interface with Streamlit.
